# Services: Companion Containers — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `services:` field to tpd profiles that declares companion containers (daemons) which start before the main container and stop after it, exposing sockets the main container mounts.

**Architecture:** A `Service` is a mini-profile (image/packages/caches/command/exposes) merged through the extends chain like any other map field. The `Service` struct includes all profile fields (even rejected ones like `network`/`ports`/`devices`) so YAML captures them and validation can reject them — without the fields present, yaml.v3 silently drops them and the validation rules are unimplementable. At launch, `LaunchWithWriter` calls `StartServices` (acquires per-service lockfiles, finds-or-starts each service, returns socket bindings + a release func). Then `CreateContainer` creates the main container (still under the lock, so the `tpd.uses-service` label is visible to a concurrent stop step). Then `release()` drops the locks. Then `RunContainer` starts+waits. A `defer`'d `StopServices` runs on every exit path. The definition hash is computed in `ResolveProfile` over the **unresolved** service definition (before template/tilde expansion) and stored on `profile.Service.Hash`, so `buildSpec` carries it to `ServiceSpec` without needing access to the pre-resolution config.

**Tech Stack:** Go 1.25, cobra CLI, docker/docker client library, gopkg.in/yaml.v3, github.com/distribution/reference. CGO off. Tests via `go test ./...`. Lint via `go vet ./...`.

- Conventional commit format (`feat:`, `fix:`, `refactor:`, `test:`, `docs:`).

- Services are allowed in both profiles and fragments.
- The `Runtime` interface grows from 2 methods to 4 (`Prepare`, `CreateContainer`, `RunContainer`, `StartServices`, `StopServices`); `FakeRuntime` and all callers must be updated in the same task as the interface change.
- The `Service` struct includes **all** profile fields (including rejected ones) so YAML captures them and validation can reject non-zero values. Without the fields on the struct, yaml.v3 silently drops `network:` etc. under a service and the validation rules never fire.
- The definition hash is computed in `ResolveProfile` over the **unresolved** `profile.Service` (before `ResolveTildes`), stored on a `Hash string` field on `Service`, and carried to `ServiceSpec.Hash` by `buildSpec`. This prevents template expansion from churning the hash.
- The lockfile (`~/.local/share/tpd/svc-<name>.lock`) is held from the start/reuse decision through the main container's `ContainerCreate`. `StartServices` returns a `release func()`; `launch.go` calls it after `CreateContainer` returns, before `RunContainer`.
- `Run` is split into `CreateContainer` (create + write files + attach) and `RunContainer` (start + pump + wait). This lets `launch.go` hold the service lock through create and release it before the long-running wait. Existing callers of `Run` are updated to call `CreateContainer` + `RunContainer`.
- Service container names use `Spec.Workspace.Mode` (not `podman bool`) to decide the rootful `<uid>` suffix: `tpd-svc-<name>` rootless, `tpd-svc-<name>-<uid>` rootful.
- `tpd.uses-service` is set on the main container's labels in `buildSpec` by scanning `cfg.Mounts` for `Service != ""` and collecting the comma-joined set of service names.
- Service `files:` are written via `CopyToContainer` inside `StartServices` (after container create, before start), owned by root (uid 0).
- Rootful socket chown: the main container's bootstrap chowns service-socket host paths to the host user before the setpriv drop. The socket host paths are added to the bootstrap's `writable` list in `Run`'s bootstrap construction.
- `StartServices` removes the service container on socket-probe timeout (self-cleanup); the `defer`'d `StopServices` handles the normal exit path.

```go
func (m *Mount) UnmarshalYAML(value *yaml.Node) error {
	type plain Mount
	var raw plain
	if err := value.Decode(&raw); err != nil {
		return err
	}
	*m = Mount(raw)
	m.ReadOnly = true
	if m.Service != "" {
		m.ReadOnly = false
	}
	if value.Kind == yaml.MappingNode {
		for i := 0; i+1 < len(value.Content); i += 2 {
			if value.Content[i].Value == "read_only" {
				if err := value.Content[i+1].Decode(&m.ReadOnly); err != nil {
					return err
				}
				break
			}
		}
	}
	return nil
}
```

```go
func (m Mount) MarshalYAML() (interface{}, error) {
	out := struct {
		Source   string `yaml:"source,omitempty"`
		Service  string `yaml:"service,omitempty"`
		Socket   string `yaml:"socket,omitempty"`
		ReadOnly *bool  `yaml:"read_only,omitempty"`
		Optional bool   `yaml:"optional"`
		Create   bool   `yaml:"create,omitempty"`
	}{
		Source:   m.Source,
		Service:  m.Service,
		Socket:   m.Socket,
		Optional: m.Optional,
		Create:   m.Create,
	}
	defaultRO := true
	if m.Service != "" {
		defaultRO = false
	}
	if m.ReadOnly != defaultRO {
		ro := m.ReadOnly
		out.ReadOnly = &ro
	}
	return out, nil
}
```

```go
func validateServices(rc RawProfile) error {
	for name, svc := range rc.Services {
		if !profileNameRe.MatchString(name) {
			return ProfileError{Path: rc.Path, Message: fmt.Sprintf("services: %s: invalid service name (must match %s)", name, profileNameRe)}
		}
		if svc.Image == "" {
			return ProfileError{Path: rc.Path, Message: fmt.Sprintf("services: %s: image is required", name)}
		}
		if len(svc.Command) == 0 {
			return ProfileError{Path: rc.Path, Message: fmt.Sprintf("services: %s: command is required", name)}
		}

func validateMountServices(rc RawProfile) error {
	for target, m := range rc.Mounts {
		hasService := m.Service != ""
		hasSocket := m.Socket != ""
		hasSource := m.Source != ""
		if hasService && !hasSocket {
			return ProfileError{Path: rc.Path, Message: fmt.Sprintf("mount %s: service requires socket", target)}
		}
		if hasSocket && !hasService {
			return ProfileError{Path: rc.Path, Message: fmt.Sprintf("mount %s: socket requires service", target)}
		}
		if hasService && hasSource {
			return ProfileError{Path: rc.Path, Message: fmt.Sprintf("mount %s: must not set source with service/socket", target)}
		}
		if hasService && m.Create {
			return ProfileError{Path: rc.Path, Message: fmt.Sprintf("mount %s: must not set create with service/socket", target)}
		}
		if hasService && m.Optional {
			return ProfileError{Path: rc.Path, Message: fmt.Sprintf("mount %s: must not set optional with service/socket", target)}
		}
		if hasService {
			svc, ok := rc.Services[m.Service]
			if !ok {
				return ProfileError{Path: rc.Path, Message: fmt.Sprintf("mount %s: service %q not declared", target, m.Service)}
			}

				return ProfileError{Path: rc.Path, Message: fmt.Sprintf("mount %s: socket %q not exposed by service %q", target, m.Socket, m.Service)}
			}
		}
	}
	return nil
```

```go
func computeServiceHash(svc Service) string {
	h := sha256.New()
	fmt.Fprintln(h, svc.Image)
	for _, p := range sortedStrings(svc.Packages) {
		fmt.Fprintln(h, p)
	}
	for _, name := range sortedMapKeys(svc.Repos) {
		r := svc.Repos[name]
		fmt.Fprintf(h, "repo %s %s %s %s %s %s\n", name, r.ExtRepo, r.URL, r.KeyURL, r.Suites, r.Components)
	}
	for _, target := range sortedMapKeys(svc.Files) {
		f := svc.Files[target]
		fmt.Fprintf(h, "file %s %o %s\n", target, f.Mode, f.Content)
	}
	for _, c := range svc.Command {
		fmt.Fprintln(h, c)
	}
	for _, k := range sortedMapKeys(svc.Env) {
		fmt.Fprintf(h, "env %s %s\n", k, svc.Env[k])
	}
	for _, k := range sortedMapKeys(svc.Exposes) {
		fmt.Fprintf(h, "expose %s %s\n", k, svc.Exposes[k])
	}
	for _, target := range sortedMapKeys(svc.Mounts) {
		m := svc.Mounts[target]
		fmt.Fprintf(h, "mount %s %s %s %v %v %v\n", target, m.Source, m.Service, m.ReadOnly, m.Optional, m.Create)
	}
	sum := h.Sum(nil)
	return hex.EncodeToString(sum[:])[:8]
}

func sortedStrings(s []string) []string {
	out := append([]string(nil), s...)
	sort.Strings(out)
	return out
}

func sortedMapKeys[V any](m map[string]V) []string {
	keys := make([]string, 0, len(m))
	for k := range m {
		keys = append(keys, k)
	}
	sort.Strings(keys)
	return keys
}
```

```go
func (d *DockerRuntime) RunContainer(ctx context.Context, spec Spec, created CreateResult) (int, error) {
	containerID := created.ContainerID
	defer func() {
		cleanupCtx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
		defer cancel()
		if err := d.cli.ContainerRemove(cleanupCtx, containerID, container.RemoveOptions{Force: true}); err != nil {
			fmt.Fprintf(os.Stderr, "tpd: warning: remove container %s: %v\n", containerID, err)
		}
	}()

	tty := spec.TTY == "true" || ((spec.TTY == "auto" || spec.TTY == "") && term.IsTerminal(int(os.Stdout.Fd())))

	var oldState *term.State
	if tty && term.IsTerminal(int(os.Stdin.Fd())) {
		var err error
		oldState, err = term.MakeRaw(int(os.Stdin.Fd()))
		if err != nil {
			return 3, fmt.Errorf("set raw mode: %w", err)
		}
		defer term.Restore(int(os.Stdin.Fd()), oldState)
	}

	hijacked, err := d.cli.ContainerAttach(ctx, containerID, container.AttachOptions{
		Stream: true,
		Stdin:  true,
		Stdout: true,
		Stderr: true,
	})
	if err != nil {
		return 3, fmt.Errorf("attach: %w", err)
	}
	defer hijacked.Close()

	if tty {
		rows, cols := terminalSize()
		if rows > 0 && cols > 0 {
			_ = d.cli.ContainerResize(ctx, containerID, container.ResizeOptions{Height: rows, Width: cols})
		}
	}

	sigCh := make(chan os.Signal, 1)
	signal.Notify(sigCh, syscall.SIGINT, syscall.SIGTERM)
	defer func() {
		signal.Stop(sigCh)
		close(sigCh)
	}()

	if tty {
		winCh := make(chan os.Signal, 1)
		signal.Notify(winCh, syscall.SIGWINCH)
		defer func() {
			signal.Stop(winCh)
			close(winCh)
		}()
		go d.handleResize(ctx, containerID, winCh)
	}

	go func() {
		for sig := range sigCh {
			if s, ok := sig.(syscall.Signal); ok {
				_ = d.cli.ContainerKill(ctx, containerID, strconv.Itoa(int(s)))
			}
		}
	}()

	if err := d.cli.ContainerStart(ctx, containerID, container.StartOptions{}); err != nil {

		defer close(pumpDone)

				if connClosed {

					return
				}

				if writeErr != nil {
					return
				}
			}
			if readErr != nil {
				return
			}
		}
	}()

		connMu.Lock()
		connClosed = true
		hijacked.Close()
		connMu.Unlock()
	}

	select {
	case err := <-errCh:
		<-pumpDone
		closeConn()
		return 3, fmt.Errorf("container wait: %w", err)

		closeConn()
```

- [ ] **Step 3: Implement `StartServices` and `StopServices`**

Replace the stub in `internal/runtime/docker_services.go`. Reference the spec's Lifecycle section for the exact algorithm. Key components:

1. **`serviceLockfilePath(name string) string`** — returns `~/.local/share/tpd/svc-<name>.lock` (use `os.UserHomeDir()` + `/local/share/tpd/`), creating the parent dir (mode 0700). Use `golang.org/x/sys/unix.Flock` for locking.

2. **`serviceContainerName(name string, mode workspace.Mode) string`** — `tpd-svc-<name>` rootless, `tpd-svc-<name>-<uid>` rootful. Use `os.Getuid()` for the uid.

3. **`serviceRunDir(name string, mode workspace.Mode) string`** — `/run/user/<uid>/tpd-svc-<name>/` rootless, `/run/tpd-svc-<name>-<uid>/` rootful.

4. **`StartServices`** — for each service:
   - Acquire lockfile (`flock`).
   - Find running container by deterministic name (ContainerList with name filter, or inspect).
   - If present and hash matches: reuse.
   - If present and hash differs: count consumers (ContainerList with `tpd.uses-service` label); if zero, stop+remove old and create fresh; if >0, warn and reuse.
   - If absent: remove any stopped same-named straggler, then create fresh.
   - To create fresh:
     1. Create cache volumes (`EnsureVolume`) + prepare subpaths (`ensureCacheSubpaths`).
     2. Build derived image if `packages:`/`repos:` declared (`DerivedTag` + `buildDerivedImage`).
     3. Create run-dir (mode 0700) + each expose's parent dir (`os.MkdirAll` with `filepath.Dir(exposePath)`).
     4. Unlink stale socket files (`os.Remove` at each `<run-dir><expose-path>`).
     5. Build mounts: cache mounts (same logic as `buildMounts` for the service's caches) + expose parent-dir bind mounts (`<run-dir>/dir(expose-path)` → `dir(expose-path)` in container) + service host-bind mounts.
     6. `ContainerCreate` with `User: "0:0"`, `WorkingDir: "/"`, `Init: true`, `Labels` (service labels + hash), `NetworkMode: ""` (engine default).
     7. Write service files via `writeContainerFiles(ctx, cli, containerID, svc.Files, 0, 0)` (owned by root).
     8. `ContainerStart`.
     9. Probe each socket with `net.Dial("unix", hostSocketPath)` — retry with 500ms interval up to 30s total. If any socket doesn't appear, remove the container and return error.
   - Populate `ServiceBindings.Sockets["<service>/<socket-name>"]` = `<run-dir><expose-path>`.
   - Do NOT release the lock yet — return it in `ServiceBindings.Release`.

5. **`ServiceBindings.Release`** — releases all service lockfiles (closes the flock fds). Called by `launch.go` after `CreateContainer` returns.

6. **`StopServices`** — for each service:
   - Acquire lockfile.
   - List running containers with `tpd.uses-service` label containing the service name.
   - If none, `ContainerStop` + `ContainerRemove` the service container.
   - Release lockfile.

```go
func checkLeakedContainers(ctx context.Context, rt *dockerRT) Check {
	f := filters.NewArgs()
	f.Add("label", runtime.OwnershipLabel+"=true")
	containers, err := rt.cli.ContainerList(ctx, container.ListOptions{All: true, Filters: f})
	if err != nil {
		return Check{Name: "leaked containers", Status: Warn, Message: err.Error()}
	}

	consumedServices := map[string]bool{}
	for _, c := range containers {
		if c.State != "running" {
			continue
		}
		if c.Labels[runtime.ServiceRoleLabel] == runtime.ServiceRoleSidecar {
			continue
		}
		if uses := c.Labels[runtime.UsesServiceLabel]; uses != "" {
			for _, name := range strings.Split(uses, ",") {
				consumedServices[strings.TrimSpace(name)] = true
			}
		}
	}

	var leaked []string
	for _, c := range containers {
		if c.Labels[runtime.ServiceRoleLabel] == runtime.ServiceRoleSidecar {
			if c.State == "running" && consumedServices[c.Labels[runtime.ServiceLabel]] {
				continue
			}
			leaked = append(leaked, strings.Join(c.Names, ","))
		} else {
			leaked = append(leaked, strings.Join(c.Names, ","))
		}
	}
	sort.Strings(leaked)
	if len(leaked) == 0 {
		return Check{Name: "leaked containers", Status: Pass, Message: "none"}
	}
	return Check{Name: "leaked containers", Status: Warn, Message: strings.Join(leaked, ", ") + " (remove with: docker rm -f ...)"}
}
```
